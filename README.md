# HongGuoEnhance

一个基于 libxposed API 102 的 LSPosed 模块，作用于红果短剧（`com.phoenix.read`）。

在短剧播放页点击**分享按钮**时，不再弹出原分享面板，而是弹出自写的"评论词条"页面：自动拉取该剧的剧评，交给 AI 总结出如 `杀伐果断 ×10`、`圣母 ×4` 的剧情词条，帮助你在开播前快速判断这部剧值不值得看。

**拒绝赤石，从我做起。**

## 功能特性

- 🎬 分享按钮重定向：播放页点分享直接打开"评论词条"页面
- 📊 AI 剧评词条：自动采集剧评并总结出高频评价词条及出现次数
- 🔍 词条统计：直观查看各词条分布
- 🚫 自定义过滤规则：按需过滤不关心的词条
- 📝 可选日志：支持模块日志与 AI 请求日志查看

## 环境要求

- 已安装并激活 [LSPosed](https://github.com/LSPosed/LSPosed)（建议 1.9.2 及以上）
- Android 10（API 29）及以上
- 红果短剧 App（`com.phoenix.read`）
- 一个可用的 OpenAI 兼容 AI 接口（如 DeepSeek、Groq 等）

## 安装与激活

1. 下载最新版 APK 并安装（见右侧 Releases）
2. 在 LSPosed 管理器中启用本模块，作用域勾选**红果短剧**
3. 冷重启（或强停）红果短剧
4. 打开模块设置，配置 AI 接口后即可使用

## 使用文档

### AI 接口配置

涉及 AI 最麻烦的就是 token 消耗，可以自行选择 DeepSeek 或者免费平台。这里推荐 [Groq 平台](https://console.groq.com/home)，选择 Qwen3.8:27B 模型，额度与速度都不错，每天免费 2k 次调用，仅用来总结剧评词条绰绰有余。

自己去申请一个 API key，其余可参照如下配置：

- BaseURL：`https://api.groq.com/openai/v1`
- 模型名：`qwen/qwen3.8-27b`

Groq 中 `qwen/qwen3.8-27b` 本就不思考，因此**取消思考**设置为*已关闭*。

勾选 **AI 走模块进程**，然后给模块加 VPN 白名单即可，当然你也可以全局开启 VPN。

### 采集参数

- 首次采集评论数建议保持默认 50
- 蛋皮加载条数保持默认 30
- 附加提示词随意：想找好剧可以让 AI 评价犀利一些、更关注缺点一些
- 过滤规则看自己

### 日志

- 大部分人不需要看日志，可以直接关闭日志
- 想看日志的，需要保持 App 与模块都在运行
- 一直无法查看的话，可以给模块 Root 权限，规避 SELinux

## 常见问题

**Q：点击分享没有反应/仍然弹出原分享面板？**
A：确认已在 LSPosed 中启用模块且作用域包含红果短剧，然后强制停止红果短剧后重新打开。

**Q：AI 请求失败？**
A：检查 BaseURL、模型名与 API Key 是否填写正确；若设备需要代理，请开启"AI 走模块进程"并配置 VPN 白名单，或直接全局代理。

**Q：总结出的词条太少或没有？**
A：部分剧评论数较少属正常现象，可适当调高"首次采集评论数"。
